## Visualizing the Material Flow in 3D

Visualizing the Material Flow introduces you to the most important tasks you will face when you create and visualize your simulation model in 3D.

3D differentiates between these object types.

- Simulation objects
- Animatable objects
- Graphic groups
- State graphics
- 3D graphics

The dialog Show 3D Graphic Structure show these object types in a tree structure.

A 3D window shows the objects with these colors:

- Plant Simulation shows a selected simulation object in green in the 3D window.

When you open a simulation object , the 3D window shows a green border on the inside.

- Plant Simulation shows a selected graphic in yellow green in the 3D window.

**Note**

We recommend to always create your models in 3D only mode . This also applies if you are only interested in the 2D view. You can model in Planning View in 3D, which corresponds to the top view in 2D. In addition, you can continuously zoom in the 3D window and 3D has better performance than 2D.

Some of the videos on the Start Page provide an introduction to 3D or introduce certain modeling tasks in 3D.
