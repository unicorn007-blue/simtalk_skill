### Command Search

Searches for functions, which you want to use or for actions, which you want to execute to solve a task.

<!-- image -->

Type words and expressions relating to your next task into the text box Find a Command .

Plant Simulation uses the names and the tooltips of the commands for the search. It lists the names of the commands first in the list of hits.

Instead, you can also press Alt+Q on the keyboard.
