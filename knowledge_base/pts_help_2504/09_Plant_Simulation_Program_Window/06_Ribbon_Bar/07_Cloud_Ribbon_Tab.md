### Cloud Ribbon Tab

Provides commands pertaining to running Plant Simulation in the cloud.

<!-- image -->

The commands apply to *.spp model files that are stored in Teamcenter Share and which are synchronized to the local computer via the Siemens Connector . Once the Siemens Connector is installed, all commands are active.

If a connection to the Siemens Connector exists, the status bar at the bottom of the program windows shows that.

<!-- image -->

**Check In [Cloud]**

#### Check In [Cloud]

Checks the *.spp model file in to the Teamcenter Share Repository .

<!-- image -->

**See also**

Check Out [Cloud]

#### Check Out [Cloud]

Checks the *.spp model file out from the Teamcenter Share Repository .

<!-- image -->

If another user has checked the file out, Plant Simulation shows who that user is. You can still save the model file though. We advise against doing so as long as somebody else is still editing the model file and has not checked it in again.

**See also**

Check In [Cloud]

**Refresh [Cloud]**

#### Refresh [Cloud]

Updates the connection to the Siemens Connector and the status of the commands Check In and Check Out .
