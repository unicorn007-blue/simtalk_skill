#### Edit 3D Properties [dialog]

Edits the properties of the selected object or of the graphic in 3D.

**Then:**

<!-- image -->

- Click on the tab Start of the ribbon bar.
- Select the command Edit 3D Properties on the context menu.
- Press the spacebar or Ctrl+3 .

<!-- image -->

<!-- image -->

The dialog box Edit 3D Properties provides all of the 3D settings relating to the selected object or graphic.

The dialog shows different tabs for the 3D properties for point-oriented objects and for length-oriented objects.

**Note**

The dialog shows the values, which you type into the text boxes, in the unit, which you select under Preferences/Model Settings &gt; Units .

<!-- image -->

**In the dialog you can:**

- View or change the Name of the selected object or of selected the graphic.
- Define the main material of the selected object in 3D on the tab Appearance of Objects and MUs .
- Define extrusion settings of the selected length-oriented object in 3D on the tab Appearance of the Length-oriented Objects .
- Define the configuration of the selected Store in 3D on the tab Appearance of the Store .
- Specify settings for the background color of the selected Frame or of the selected folder on the tab Background .
- Edit the settings of a barred area , which you inserted into you simulation model on the tab Barred Area Settings .
- Edit the settings of a box , which you inserted into you simulation model on the tab Box Settings .
- Specify settings for the camera animation of the selected Frame on the tab Camera Animation . Only the Frame provides this tab.

<!-- image -->

- Activate or deactivate captions , which you created, on the tab Captions . You can show or hide the

<!-- image -->

Names and/or Labels of the objects in 3D by clicking ribbon tab.

- Edit the settings of the factory walls , which you inserted into you simulation model on the tab Factory Walls Settings .
- Edit the settings of a fence , which you inserted into you simulation model on the tab Fence Settings .
- Specify settings for showing the fi ll level of the Buffer on the tab Fill Level .
- Activate or deactivate graphic inheritance and the inheritance of the visibility and select settings for visibility of the object toward the outside on the tab Graphics . In addition, you can show the graphics structure of this object and set if the object is an obstacle for the worker or not.
- Set graphic sequences , which the Worker uses when he is just walking or walking and carrying a part on a Footpath or when he is walking freely on the tab Graphic Sequences . This ensures that the Worker looks as realistic as possible in your simulation model.
- Select if the graphic of the object is an obstacle for the Worker on the tab Graphic Settings .
- Define settings for rotating and translating the animation joints of the animation objects on the tab Joint .
- Specify settings for the material of graphics on the tab Material .
- Edit the settings of a mezzanine , which you inserted into you simulation model on the tab Mezzanine Settings .
- Specify settings for the animation of the parts on the material flow object on the tab MU Animation . All material flow objects provide this tab.
- Specify point cloud settings for the Frame on the tab Point Cloud .
- Define settings for poses of the joints of the animation objects on the tab Poses .
- Edit the settings of a rack , which you inserted into you simulation model on the tab Rack Settings .
- Specify settings for the animation of the robot arm of the PickAndPlace Robot on the tab Robot Arm Animation .

Only the PickAndPlace Robot provides this tab.

- Specify settings for the animation of objects , which you can insert into a Frame , and for the animatable objects on the tab Self Animation .

All material flow objects provide this tab.

- Edit the settings of a staircase , which you inserted into you simulation model on the tab Stairs Settings .

- Specify properties of the state graphic of the objects on the tab States . All material flow objects provide this tab.
- Specify transformation settings for graphics on the tab Transformation .
- Click Open Simulation Settings or Open to change to the object properties .
- The Navigate Menu , the View Menu , and the Help Menu provide additional commands.
