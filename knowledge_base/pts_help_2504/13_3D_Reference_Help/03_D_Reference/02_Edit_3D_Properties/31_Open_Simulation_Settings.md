#### Open Simulation Settings

To open the dialog of the corresponding object in 2D, click this button with the icon of the 2D object. You can then edit simulation-relevant settings.

<!-- image -->

The button shows the icon of the respective object in 2D, for example for the Station .

<!-- image -->

Instead, you can also select Navigate &gt; Open .

To close the opened 3D dialog after the respective 2D dialog has been opened, hold down Shift while you click the 2D button. Be aware that Plant Simulation will not apply changes you made in the 3D dialog.
