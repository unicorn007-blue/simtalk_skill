#### Tab Factory Walls Settings

Factory Walls Settings

Change the settings of the selected Factory Walls in your simulation model.

<!-- image -->

To set if the factory walls are an Obstacle for the Worker , select the respective setting from the dropdown list.

<!-- image -->

You can also edit the dimensions of the factory walls by clicking Show Manipulators on the Edit ribbon tab. The Barred Area Settings reflect this change.

You can set one of the dimensions to 0 by dragging the respective manipulator.

<!-- image -->

**Show Manipulators**

You can edit the dimensions of the object by clicking Show Manipulators on the Edit ribbon tab or press M on the keyboard. The factory walls settings reflect this change.
