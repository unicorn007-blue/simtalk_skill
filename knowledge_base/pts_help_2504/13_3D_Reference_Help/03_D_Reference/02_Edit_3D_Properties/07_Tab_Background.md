#### Tab Background

Background [tab] - Frame in 3D

Define the background color of the selected Frame on the tab Background .

<!-- image -->

You can:

- Assign a Background Color of Its Own . Once you select the check box, 3D activates the other settings on the tab.
- Select the Base Color .
- Select settings for the Corner Brightness of the four corners of the Frame window.

<!-- image -->

**Note**

If you do not define a background color, 3D uses the background color of the parent object of the selected object.

See also

Set the Background Color of the Scene

##### Assign a Background Color of Its Own

To assign a background color to the selected Frame , select this check box.

<!-- image -->

3D then activates the other settings on the tab.

If you do not want to assign a background color to the selected Frame/scene , clear the check box. 3D then uses the background color of the parent Frame of the selected Frame .

##### Base Color

Base Color

Select the Base Color for the background of the Frame from the drop-down list.

<!-- image -->

You can select one of the predefined colors, or you can click More Colors and click the Select button to select a color in the color matrix. Then click OK . Plant Simulation shows this color next to More Colors and uses it as the active color.

In addition, you can change the Corner Brightness of the four corners of the scene window.

SimTalk

\_3D.BackgroundColor [SimTalk]

##### Corner Brightness

To define a color gradient, i.e., the brightness of the background color, first select the Base Color .

Then drag the slider for each of the four corners of the Frame window to make the respective corner darker or brighter. The top left slider sets the settings of the top left corner of the Frame window, etc.
