#### Tab Rack Settings

Rack Settings

Change the settings of the selected Rack in your simulation model.

<!-- image -->

Here you can also select if the rack is an Obstacle for the Worker . The posts of the rack do not create a worker obstacle by default.

**Show Manipulators**

You can edit the dimensions of the object by clicking Show Manipulators on the Edit ribbon tab or press M on the keyboard. The rack settings reflect this change.
