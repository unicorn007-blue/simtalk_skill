# 5. Using Plant Simulation X

## Plant Simulation X

Plant Simulation X provides a version of Plant Simulation with cloud-based licenses.

The features of Plant Simulation X are identical to those of Plant Simulation desktop version, providing the same user experience and the same .spp data file, which is stored on your local computer. Plant Simulation X enables you to distribute and update the software and collaborate with colleagues on your desktop.

Siemens manages the licenses you purchased, the configuration, and the updates for Plant Simulation X .

Plant Simulation X covers these components:

- Plant Simulation X Products and Features gives an overview of the products and their features.
- Install Plant Simulation X from Siemens Software Center describes what you need to do to download and install Plant Simulation on your computer, and use cloud licenses with it.
- You also have to install software updates from the Siemens Software Center .
- Start Plant Simulation X describes how to start Plant Simulation X on your computer.

## Install Plant Simulation X from Siemens Software Center

As soon as you or your Enterprise Cloud Account (ECA) administrator have set everything up and assigned you your license, you will receive a Welcome email inviting you to download and install Siemens Software Center .

Proceed as follows:

- In the Welcome email , click the link and sign in with your Siemens account.

**Note**

If you do not have a Siemens account, click the link to create a new account on the sign-in page.

- Download and install Siemens Software Center .
- Click Siemens Software Center and sign in with your credentials and account.

<!-- image -->

**Note**

Siemens Software Center shows your license package.

It also shows licenses for additional products that are assigned to you.

- When the Siemens Software Center is installed on your computer, you can install Plant Simulation X . If you have licenses for other applications, you can also install them from here.

Click Install .

**Note**

If software updates are available, Siemens Software Center installs the latest updates.

You also install any software updates published after the initial installation from the Siemens Software Center .

When installation is complete, the label of the Install button changes to Open in the Siemens Software Center .

- If software updates are released after you complete the installation of Plant Simulation X , the label of the Open button changes to Update .

Either click Update to update your Plant Simulation X installation or click Install Options .

This opens the Install Options dialog box.

- Select the Selected Version you want to install and click OK .

When the update is complete, the label of the button changes back to Open in the Siemens Software Center .

- Start Plant Simulation X .

## Start Plant Simulation X

After you installed Plant Simulation X on your computer, you can start it. Plant Simulation X validates your license with the Siemens Cloud. You only have to log in once per day after validation.

**Note**

When you start Plant Simulation X for the first time, it opens the dialog License Setup .

To use a license provided and managed by Siemens in the Cloud for Plant Simulation X , click I have a cloud license which I want to use.

<!-- image -->

Create or open a model in Plant Simulation X . This opens the Siemens Log in page.

Type in your Email address and click Continue .

<!-- image -->

When the window opens again, type in your Email address a second time and click Continue again. After successfully signing in, close this window.

<!-- image -->

You can now start working with Plant Simulation , either by creating a new model or by opening an existing model and continue working with it.

[https://www.sw.siemens.com/en-US/siemens-software-center/](https://www.sw.siemens.com/en-US/siemens-software-center/)

## Work Offline During an Internet Outage

Plant Simulation X lets you work offline for a certain time during a network outage or an Internet outage.

Your Plant Simulation X license requires an Internet connection 24 hours after you initially logged in to your Cloud account.

Plant Simulation X requests a named-user license , which is bound to you as a person. If you need to work offline from a certain day on, we advise to explicitly renew the license as late as possible before you lose the Internet connection.

To renew your license, exit and re-start Plant Simulation and load a model or create a new model, which will then request/renew the license.
