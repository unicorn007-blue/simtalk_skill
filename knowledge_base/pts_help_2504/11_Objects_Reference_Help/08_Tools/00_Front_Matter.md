## Tools

Plant Simulation provides the tools to assist you in solving various modeling tasks. We modeled the tools as application objects within a Frame .

Plant Simulation provides these and a number of other tools:

<!-- image -->

- Use the BottleneckAnalyzer for analyzing and displaying the flow of parts through a plant and thus identify bottlenecks.
- Use the EnergyAnalyzer for analyzing the energy consumption of the selected machines in your plant.
- Use the ExperimentManager for running experiments with your simulation model. You can also use it to run distributed simulations .
- Use the GAWizard for integrating genetic algorithms into an existing simulation model. Use it for optimizations in which the evaluation is based on a simulation run as well as for optimizations in which the evaluation is based on calculations in methods.
- Use the Neural Network for deducing a function from observations. This is particularly useful in applications, where the complexity of the data or task makes the design of such a function by hand impractical.
