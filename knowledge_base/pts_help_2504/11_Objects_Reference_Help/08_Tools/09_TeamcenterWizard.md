### TeamcenterWizard

Use the TeamcenterWizard for exchanging data with Teamcenter .

**Image**

<!-- image -->

The TeamcenterWizard library consists of the TeamcenterWizard , the TeamcenterReport , and the TeamcenterAttributeExplorer .

Description

To add the TeamcenterWizard to the Class Library , click Manage Class Library &gt; Libraries &gt; Tools &gt; Wizard for Teamcenter on the Home ribbon tab. Plant Simulation adds the TeamcenterWizard to the tab Teamcenter in the Toolbox .

<!-- image -->

<!-- image -->

The TeamcenterWizard assists you in importing data from Teamcenter and in generating a simulation model with this data.

<!-- image -->

The help for the TeamcenterWizard is integrated in the object itself. Select Help &gt; Help on Object to open it.
