### Tools

- Use the Sequential Sampler for starting a simulation study, which consists of a single, non-terminating simulation run. It analyzes a single target value.
- Use the Statistics Tools for analyzing the statistics values that your simulation runs determined.
- Use the TeamcenterWizard for exchanging data with Teamcenter .
- Use the TransferStation for loading, unloading, and reloading parts.
- Use the VariantsGenerator for creating frequency tables for attribute variants, which objects of type Source with the setting Attributes &gt; MU Selection &gt; Random use.

**Note**

We modeled most of the tools as application objects in a Frame . For this reason opening help with F1 and What's This Help in the dialogs of the objects do not work. To open help for the tool, select Help &gt; Help on in its dialog.

We modeled the dialogs of the objects with the object Dialog . The dialog windows of the objects do not use the standard Siemens PLM theme, but your Windows theme.

To add any of the tools to the Class Library , click Manage Class Library &gt; Libraries &gt; Tools on the Home ribbon tab.
