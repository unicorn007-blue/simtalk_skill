## Information Flow Objects

Plant Simulation provides the information flow objects to supply the simulation with production data.

<!-- image -->

<!-- image -->

- Use the Method for programming controls, which other objects start, and which Plant Simulation then executes during the simulation run.
- Use the Variable for storing data over an extended period of time.
- Use the PythonModule for utilizing Python code in a Plant Simulation model with full access to the Plant Simulation object model from within the Python code.
- Use the lists and tables DataList , DataQueue DataStack , DataTable , and TimeSequence for storing and managing data.
- Use the Trigger and the Generator for controlling when and how mobile objects ( MUs ) are created.
- Use the AttributeExplorer for managing the attributes defining the settings of the individual stations in your simulation model at a single, central location.
- Use the FileInterface for accessing data you create and store in other programs in ASCII format.
- Use the FileLink for placing a link, i.e., a shortcut to a file into a Frame in your simulation model.
- Use the XMLInterface for reading and extracting data stored in XML files.

The Inter-Process Communication Interfaces and the Database Interfaces are also part of the information flow objects .
