## Objects Reference Help

The Plant Simulation reference help describes the built-in objects and the settings they provide in detail.

Plant Simulation provides these objects by default. Your license type determines, which of the objects you can use in your simulation models.

- Fluid Objects
- Resource Objects
- Mobile Units [MUs]
- Information Flow Objects
- Display and User Interface Objects
- Tools
