#### Standard Transfer Behavior

If a material flow object has more than one successor, Plant Simulation cyclically moves the MUs on to each of it succeeding stations in turn.

If the successor of the object is full, failed or paused, Plant Simulation blocks moving the part until this station is ready to receive parts again.

You can change the standard transfer behavior on the Tab Exit of the material flow objects.
